# Jenn's Command Center

CINC Marketing's tracking hub for the three departments Jenn is responsible for:

- **Events** — in-person tradeshows and webinars
- **Content marketing** — blog posts, white papers, client testimonials, buy-side industry briefs, press releases
- **Product marketing (GTM)** — past, current, and future go-to-market projects

## Viewing the site

Open `index.html` in any browser, or visit the published GitHub Pages link once enabled.

## Updating the site

All data lives in `data.js`. Open Claude Code in this folder and describe the change in plain English, for example:

> "Add a tradeshow: Inman Connect, Jan 27–29 2027, New York, status planning"
> "Mark the MMS press release as published"
> "Move Call AI to past — it launched Oct 1"

Claude edits `data.js`, commits, and pushes. See `CLAUDE.md` for the details.
